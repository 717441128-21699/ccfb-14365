# 攻城战编队推演沙盘

纯 TypeScript 实现的大规模阵型/行军/接敌模拟，配套 Canvas2D 的阵型编辑页与对战沙盘页。
核心逻辑与渲染解耦，可在浏览器运行，也可在 Node 无头环境做性能基准与冒烟测试。

## 运行

```bash
npm install
npm run dev      # 本地开发，打开阵型编辑 / 对战沙盘两个页面
npm run build    # 类型检查 + 生产构建
npm run bench    # 无头性能基准（1000 单位 / 10 阵 / 60s）
npm run smoke    # 端到端冒烟测试（编队、行军、接敌、性能不变量）
```

## 需求对照

### 1. 编队（`src/core/formation.ts`）
- 五种阵型：密集方阵 `phalanx`、横队 `line`、楔形 `wedge`、方阵城 `square`、纵队 `column`。
- 混编按兵种比例排位：长枪/长矛前排、盾剑中层、弓弩后排；骑兵占两翼外缘，攻城器械居后居中；
  方阵城按环层分配（外环硬壳、内环弓弩、核心器械）。
- 每个单位绑定一个槽位（slot），槽位以阵型锚点为原点、+x 为正面，靠局部→世界变换随锚点运动。

### 2. 行军（`src/core/movement.ts` + `pathfinding.ts`）
- 锚点沿 A* 弦切路径推进，限角速度转弯；单体用「slot 速度前馈 + 位置误差比例项」追踪槽位，
  外侧单位按到转向轴的横向距离获得速度加成，实现**外侧走快、内侧走慢**。
- 窄桥/窄走廊状态机：前方探测到水域且正面宽度不足时自动切纵队，过河（锚点踩上非水面）后
  带滞回与展开冷却地恢复主战型，杜绝桥口来回抖动。
- 空间哈希分离力防止同队穿插；地形速度乘区按脚下采样；混编速度由编队内最慢兵种封顶。
- 阵型保持：稳态下 100% 单位相对槽位误差在半个身位（0.8m）内（见 bench）。

### 3. 接敌（`src/core/combat.ts`）
- 前排单位在交战距离内锁定最近敌人、停下厮杀；阵亡后同列单位按局部坐标匹配依次补位，
  单向、确定性，不回抖。伤亡累积到阈值按存活兵种比例紧凑重排。
- 远程单位（弓手/弩手/投石机）行进间减速射击、周期投放投射物；隔河有水面遮挡，不能隔空交战。
- 兵力低于 32% 触发溃退；脱战后自动开窗收拢残阵。
- 远程兵与攻城器械混编时，整队速度按最慢单位协调。

### 4. 页面与性能
- 阵型编辑页：选阵型、拉兵种人数滑杆，实时预览成型与槽位骨架。
- 对战沙盘页：播放/暂停/倍速、点选阵型再点地图下令（自动寻路过桥）、HUD 实时显示帧耗时/误差/兵力。
- 性能：1000 单位十阵，固定 30Hz 步长，**每帧逻辑 p99 ≈ 4.5ms（预算 5ms）**；
  热路径用空间哈希、单位/槽位索引、平方距离、索敌节流与目标缓存控制复杂度。

## 目录结构

```
src/core/        纯逻辑，无 DOM 依赖
  math.ts        向量、确定性随机、值噪声
  classes.ts     种子生成的八兵种数值表
  types.ts       领域类型
  terrain.ts     程序化地形（河流、双窄桥、地表）与通行/走廊探测
  pathfinding.ts A* + 弦切路径平滑
  formation.ts   阵型槽位几何、混编排位、阵亡补位
  movement.ts    锚点状态机、窄桥纵队、单体转向、空间哈希
  combat.ts      目标检索、近战/远程、士气溃退、投射物
  runtime.ts     编队/世界运行时结构
  scenario.ts    1000 单位隔河会战场景、编辑器预览场景
  simulator.ts   固定步长主循环、军令接口、帧耗时测量
src/ui/          Canvas2D 渲染器与两个页面
src/perf/        Node 无头基准与冒烟测试
```

## 关键设计取舍

- **逻辑零 DOM 依赖**：`src/core` 不引用浏览器 API，同一份代码驱动页面与无头测试。
- **固定步长 + 累积器**：渲染帧率可变，逻辑始终 30Hz 确定性推进，便于复现和测量。
- **受控过渡不计入稳态误差**：成列/展开/接敌/重排期间的大位移是预期行为，基准只统计稳定行军态，
  并单独报告过渡峰值，数字口径诚实可解释。
- **GC 控制**：空间哈希桶复用、投射物 swap-pop、热路径无闭包/临时对象，p99 稳定在预算内；
  偶发 max 尖峰来自引擎 GC，单独列出不作为稳态结论。
